# project-005 分任务总览

## 目标

把 `project-005-AI创意美术教学平台MVP` 拆成可持续推进的模块任务，避免每次都在一个超大上下文里处理全部功能。

## 执行原则

- 不复制源码，不拆成多个独立 npm 项目。
- 所有代码仍在当前 Vue3 + Node 工程内维护。
- 每次继续任务时，优先指定一个分任务编号。
- 每个分任务完成后，更新对应 `执行记录.md` 和 `验收清单.md`。
- 跨模块修改统一记录到 `99-集成测试`。

## 推荐继续顺序

1. `03-智能体与模型配置`：先把 API、模型、智能体可调用链路稳定下来。
2. `05-PPT模板库`：再明确模板上传、分类、授权和学生端可见规则。
3. `06-学生报告生成`：最后重做资料整理、大纲、Image2 页图生成和导出逻辑。
4. `99-集成测试`：每次阶段完成后做统一验证。

## 使用方式

后续可以直接这样发任务：

```text
继续 project-005 的 05-PPT模板库，先做后台模板上传和批量授权。
```

或：

```text
继续 project-005 的 06-学生报告生成，只处理 PPT 大纲和页图生成流程。
```
