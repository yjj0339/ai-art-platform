同一份素材，不同的排法和皮肤

下面每一张都是 390×844 的手机页，内容完全一样——8 岁的林小雨画了一栋"会飞的房子"。区别只在两件事：这一页怎么摆（排法）和整体长什么样（皮肤）。你看到的所有灰色字都是真实会出现在报告里的内容，没有一句是"我保存了 N 个作品版本"这类套话。

排法 8 种，开发一次永久复用 皮肤 任意增加，换肤不动页面 换风格 不重新生成、不花钱
A

同一页，四套皮肤

四个页面用的是同一种排法、同一段文字、同一张画。你只需要看：气质差得够不够远，选起来够不够快。以后加风格，就是在这里加一张脸。

B

同一皮肤下，八种排法

孩子的内容是变化的：只有一张画、写了三百字、有四张草稿、或者还没有成品。系统根据"图几张、字多少、记录了什么"，自动挑一种能装下的排法，永远不留空位、不切断句子、不弹"请先调整模板"。

C

封面：家长点开的第一眼

封面决定"这份报告值不值得往家长群里发"。同一个项目名，三种气质。

你可以直接用眼睛验收这四条

  1. 没有一步需要孩子去调模板。 上面 15 页里，没有任何一页出现"高度不足""请调整"。
  2. 没有空图位。 只有一张画时用一图排法，有四张草稿时用拼贴，页面永远填满。
  3. 句子没被切断。 长文用便签页或过程页承接，不是把一段话按字数劈成三页同版式。
  4. 装饰只做装饰。 胶带、印章、纸纹都在文字下面，内容改成什么都不会被挡住。
