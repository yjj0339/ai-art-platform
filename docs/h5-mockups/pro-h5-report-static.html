家里那张台灯太大，一放练习本、橡皮和尺子就挤得没地方。晚上写字的时候，光一大片照到旁边，妹妹已经睡了，总被吵醒。我就想：能不能做一个能夹在桌边的小灯？灯头可以转，想照哪儿就照哪儿；光收得紧一点，只照在本子上。

后来量了桌子，夹子要能夹住 3 厘米厚的边，灯颈得能弯下来贴近纸面，这样影子才不会挡字。想清楚这几点，我才开始画。

我先在草稿纸上画了三个夹子的样子：一个是两片平的，一个带弹簧，还有一个像鹦鹉嘴一样上下咬合。比来比去，觉得鹦鹉嘴那版夹得最稳，也不硌手，就选了这个。

灯颈一开始画的是直的，可是一弯腰写字，灯光就被自己的手臂挡住，纸上黑一片。我把它改成两节，中间加一个能转的关节，弯下来就能贴着手边照。灯罩也改了三遍，最后一次才把开口收窄。
