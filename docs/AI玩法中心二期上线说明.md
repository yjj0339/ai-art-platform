# AI 玩法中心二期上线说明

## 已实现能力

- 后台使用现有无限画布配置图像与视频玩法工作流，不存在第二套画布。
- 玩法中心支持类型、状态、模型和关键词筛选，以及草稿、测试、发布、下线、永久删除、复制和历史版本恢复。
- 学生页面使用 12 列半自由栅格，可配置图片、提示词、下拉、开关、比例、数量、说明、生成按钮和结果组件。
- 后台预览与学生正式页面共用 `AiSkillStudentPage`，避免两个页面表现不一致。
- 发布后学生点击 AI 绘画或 AI 视频左侧玩法卡片，进入通用玩法运行页；普通新增玩法不需要新增 Vue 页面。
- 服务端继续使用不可变发布快照、机构权限、每日限额和任务记录；图像同步返回，视频异步查询并支持刷新恢复。

## 数据库升级与旧玩法清理

1. 使用 `pg_dump` 完整备份正式数据库。
2. 执行 `pnpm db:migrate`，增加 `draft_revision` 并更新表结构。
3. 确认不再需要旧表单/JSON玩法后，显式执行 `scripts/migrations/20260814-reset-ai-skills-v2.sql`。
4. 清理脚本默认拒绝运行；只有设置 `app.confirm_ai_skill_reset=YES` 后才会在事务中删除玩法及其关联记录。
5. 清理完成后在后台重新创建至少一个图像玩法和一个视频玩法，真实测试成功后发布。

## 发布流程

1. 填写基础信息和模型运行参数。
2. 在“工作流配置”中使用原无限画布连接输入、生成和结果节点。
3. 在右侧布置学生页面并绑定画布节点字段。
4. 保存草稿，使用学生预览数据完成真实测试。
5. 测试成功后发布。后续编辑只影响草稿，重新发布后学生才读取新版本。

## 当前边界

- Agnes 支持图像和视频；火山引擎第一版只用于图像。
- 不支持上传 Python、ComfyUI、Docker、脚本节点或任意外部 HTTP 节点。
- 学生上传图片目前沿用现有前端图片数据传递方式；正式大规模上线建议接入 COS 私有上传和签名访问。
- 2 核 4G 服务器只承担配置、权限、文件转发和任务调度，不在本地运行生成模型。
- 真实 AI 测试需要服务器已配置供应商密钥、余额和可用网络。
