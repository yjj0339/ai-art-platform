# 内容审核与系统精选实施及验收说明

日期：2026-10-16。结论：本轮开发与隔离验收已完成，真实 AI 看图、真实计费和线上部署尚未验证。用户已明确选择本轮不调用付费 AI，学校已有授权由管理员登记。AI 审核、自动精选、自动上架默认关闭，平台费用上限默认为 0。

## 已交付功能与使用入口

后台进入「内容审核」，原有入口直接使用新面板，没有另建第二套审核页面。

- 「规则设置」：AI 审核、系统精选、自动上架、隐私加强和相似检测开关；审核要求与优秀标准分别启用和填写；选择模型，配置评分门槛、日次数、机构预算及单次费用上限。关闭自定义要求会保留文字，但不发送给模型。保存到服务端后生效，支持并发冲突提示、失败保留和未保存离开提示。
- 「审核队列」：读取真实状态、统计和分页；查看审核图片、理由及评分，填写理由后人工通过、驳回、下架或恢复上架。请求结果不明的任务只有管理员明确确认可能再次计费后才能重审。
- 「审核记录」：查看规则、授权、模型判断与人工处理记录。
- 「学校授权」：按管理员可管理的学生范围登记已有授权依据，或撤回授权。登记范围需包含图片向所选审核供应商发送及平台公开展示。学校授权不会替学生开启参与开关。
- 「选择作品试审」：使用当前表单草稿，不保存规则、不上架作品，计入费用与次数。当前平台预算为 0，因此真实试审禁用并说明原因。

学生在「我的素材库」或工作台可以开启一次性的「允许系统自动精选最终作品」。开启后，后续保存的最终绘画作品可由服务端入队，不必逐件主动投稿。关闭后停止后续精选；已经公开的作品可单件撤回，也可撤下全部系统精选作品，主动投稿不受批量撤下精选影响。学生仍可主动投稿，并必须确认公开展示说明。

作品广场只读取服务端公开作品，支持课程分类及分页。没有公开作品时显示空状态，加载失败时显示错误和重试。正式登录模式不再用演示作品补空列表。公开封面和详情只展示通过审核的固定版本，昵称统一为「小画家」，不公开原文档、提示词、内部审核结果或授权依据。

## 执行与数据保护

任务、规则、授权、审核结果、预算预留与发布快照存入 PostgreSQL。后台任务约每 3 秒运行一次，通过数据库锁跨进程串行处理；学校授权与发布操作互斥，预算按北京时间自然日原子预留。

模型每次只请求一次，超时、限流、余额不足、空结果、非法结构和供应商错误均不自动公开。请求已发出但结果不明时转人工，避免重启后重复付费。安全不通过时，高评分不能抵消；可疑结论转人工；自动精选低分标记未入选，主动投稿不受精选分数门槛限制。

图片读取校验真实字节、本人资产归属、像素及大小，转换为 JPEG 快照；审核输入最长边 1600 像素、最大 3MB、原图最多 16×1024×1024 像素，只支持静态 PNG/JPEG/WebP。远程图复用现有受控 HTTPS 读取。首次精确重复或可选近似命中转人工，发布前再次检查。dHash 只用于疑似相似提示，不作为侵权判定。

学生撤回、学校撤授权、管理员下架和原文档删除会使公开列表及取图失效，迟到 AI 不能覆盖人工结论。已上架作品继续修改时，广场保留已审核版本，新版本另行处理。新发布不放宽原始用户文档的行级权限。

## 未验证项及启用前置条件

1. **真实 AI 调用未验证**：遵照用户不付费选择，未将学生作品发送给真实审核供应商。真实识图准确率、误判率、提示注入抵抗、响应时间、供应商安全策略和实际费用均需后续小样本验证。
2. 审核适配目前要求供应商支持 OpenAI 兼容 `chat/completions`、图片输入和 JSON 输出；候选来自已配置的文本模型，显示候选不代表具备视觉能力。需成功试审并由管理员核对图片描述后再启用；平台地址、密钥或模型变化会使原验证失效。
3. 日预算按管理员填写的单次费用上限预留，是内部成本限制，不是实时账单。填错价格不能保证供应商实际收费低于预算，启用前需核实最坏费用。
4. 学校授权、学生参与、可用视觉模型、正数平台预算及机构预算缺一不可。视频、3D、H5、整份画布、历史作品全库扫描不在本期。
5. 队列分页；授权页最多读取 500 名学生，试审列表最多 200 件，记录最多最近 200 条，本人投稿最多 500 条。更大规模需增加检索/分页，队列全局串行的处理能力也需结合真实模型耗时评估。
6. 本次迁移核实了现存 1 条历史记录和重复结构执行；没有覆盖真实环境所有历史数据组合，也未在业务库执行恢复脚本或线上发布演练。上线前需备份目标库并检查历史已发布作品；无快照的历史已公开作品会被受控迁移阻止，需单独人工处理。
7. 构建保留现有 Sass legacy API、PURE 注释、空 chunk 和混合导入警告；未修改这些无关模块。课程学习、批量素材操作、画布、视频、3D、H5 全流程未在本轮逐项重测。

## 部署、停止与回退

详细命令见[部署说明](部署说明.md)。本机已迁移，无需重复执行。

目标环境先备份 PostgreSQL 与完整 `AI_DATA_DIR`，用 `node scripts/migrate-gallery.mjs` 备份检查，确认结果后以 `--apply` 执行受控增量；新环境的 `pnpm db:migrate` 同时加载基础与审核结构。前后端同步更新，保留服务器环境变量、原文档与私有资产，禁止用本机 `server/data` 覆盖服务器。

停止新模型请求可将 `GALLERY_WORKER_ENABLED=false` 并重启；暂停 AI 审核或自动上架也可在后台保存关闭。前者停止后台处理，不替代撤下已公开作品；需要停止展示时应人工下架或撤回授权。

回退前关闭自动功能并保留新增数据，恢复相容的前后端代码。备份内 `恢复原访问策略.sql` 仅用于与旧代码配套恢复原访问策略及触发器，不删除新增字段、任务、授权或作品；会恢复旧版权限行为，须先检查当时已公开作品并在目标环境演练。不要把其当作删除新数据的一键降级脚本。

本轮达到「开发与隔离验收」完成标准，未达到「真实 AI 及线上正式启用」标准。工作区包含其他任务的已有修改，不能整包提交；划清本任务差异、复核敏感文件与部署前置条件后可进入提交准备，尚不适合作为已通过真实模型验收的稳定里程碑。
