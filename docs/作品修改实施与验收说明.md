## 技术实现与边界

- 前端：`src/components/ArtworkEditor.vue`，接入 `PaintStudio.vue`、`StudentPortfolio.vue`、`StudentWorkbench.vue`，沿用 `projectStore` 的项目和服务端文档状态。
- 图片处理：`server/artwork-image.js` 和 `src/utils/artworkAdjust.js`。使用 sharp 统一方向和 sRGB，生成 PNG；模型输入按配置等比缩放补边，返回时裁切恢复原尺寸。只融合选区内部，未选区域逐字节保留规范化原图的 RGBA；不承诺原始 JPEG 文件字节或元数据保持不变。
- 编辑服务：`server/artwork-editor.js`。复用已有用户文档和私有图片资产；待保存结果是用户关联文档。仅服务端登录的学生本人可编辑自己的项目和图片；教师、家长、管理员不能通过本接口代改。
- 预览与保存分开。保存以文档版本做并发校验；冲突后重新加载再保存，复用已生成结果，不再次调用模型；重复保存同一结果不会新增重复版本。
- 修复验收时发现的原有草稿问题：草稿不再复用正式项目文档编号，避免自动保存覆盖项目；同步异步写入后的文档编号，避免重复草稿。
- 兼容旧项目 `thumbnails` 列表及 `preview/url/background` 图片来源。没有新增 SQL 表或迁移，不改变既有路由和项目字段语义。

接口：

| 接口 | 用途 |
|---|---|
| `GET /api/ai/image/edit/capabilities` | 返回已声明且启用的编辑模型 |
| `GET /api/ai/image/edit/source?documentId=…&versionId=…` | 校验来源权限后返回规范化原图 |
| `POST /api/ai/image/edit` | 接收项目文档、版本、操作、参数或遮罩；生成私有待保存结果 |
| `POST /api/ai/image/edit/save` | 按 `pendingId`、`expectedVersion` 保存项目新版本 |

## 成本、稳定性与安全限制

- 支持静态 PNG、JPEG、WebP；单图最大 25MB，像素上限为 16 × 1024 × 1024。AI 模型输入尺寸限 1024×1024、1536×1024、1024×1536。
- 每次生成一张；每个学生同时最多一项编辑；AI 默认每分钟最多三次。调整不调用 AI，不计入 AI 频率。
- 默认超时 180 秒，不自动循环重试。对限流、余额不足、内容安全拒绝、空结果、格式错误、上游失败和超时分别返回中文提示。
- 提示词有基础拒绝检查，并处理供应商安全拒绝；这不替代供应商完整的内容审核，正式启用需确认其安全能力。
- 远程原图及结果只读取公网 HTTPS 图片，限制体积，固定已检查的 DNS 地址，拒绝私网和重定向。学生作品按用户数据处理；启用前应在产品告知中说明编辑会向所选模型供应商发送原图、遮罩及描述。
- 并发和频率限制保存在当前服务进程，多实例部署前需要统一限流。未保存预览及对应文档暂不自动清理，需要监控持久化目录和数据库容量；本期未实现配额和生命周期清理。
