---

## 一、一句话说清

把现在的「模板」拆成三样东西——**皮肤（长什么样）、排法（这页怎么摆）、配方（每章允许哪几种摆法）**，让内容和视觉彻底分开。

做一次 8 种排法，以后**加风格只换皮肤**；内容多内容少，系统自己挑排法。旧的模板编辑器冻结，不再新增模板。

---

## 二、你要的四件事，方案分别怎么给

| 你的诉求 | 现在为什么做不到 | 新体系怎么解决 |
| --- | --- | --- |
| **风格要多** | 一套风格＝手工摆 8 页，10 套＝80 页手工，加风格就是加工时 | 皮肤 × 排法 × 密度 = 240 种页面长相，**手工摆放量归零** |
| **排版要智能** | AI 只被允许挪坐标，等于让 AI 当拖拽工 | 智能分三级，**九成靠"读懂内容"，不靠大模型**，不花钱 |
| **适应各种内容** | 页面位置钉死，内容一变就要重摆 | 缺内容就少一页、内容多就换排法或加页，**永远不报错** |
| **学生端好用** | 二十张缩略图选风格，选择困难 | 两次点击：**先选气质，再选颜色**，风格库后台无限加，前台不变复杂 |

## 三、体系怎么搭

### 3.1 皮肤（一套风格 = 一份配置，不是一堆页面）

一套皮肤只有这些字段，改完立刻作用到所有页面：

| 字段 | 说明 | 举例 |
| --- | --- | --- |
| 名称与封面图 | 前台展示用 | 清爽水彩 |
| 配色 6 色 | 主色 / 辅色 / 强调色 / 页面底 / 纸张 / 文字 | 蓝白系 |
| 字体 2 种 | 标题字体 / 正文字体 | 标题用手写体，正文用黑体 |
| 纸纹 | 无 / 格纹 / 宣纸 / 牛皮 / 点阵 | 细格纹 |
| 装饰素材组 | 胶带、便签、图钉、贴纸（一组 PNG） | 蓝胶带 |
| 圆角与阴影 | 利落 / 柔和 / 手工感 | 柔和 |
| 标题样式 | 居中 / 靠左 / 带下划色块 / 带引号 | 靠左带色块 |
| 页脚语 | 报告底部一行小字 | 观察 · 探索 · 创造 |
| 装饰用量 | 多 / 中 / 少 | 少 |

**新增一套风格 = 填一张表 + 传一组贴纸，10～20 分钟。** 不需要摆任何一页。

### 3.2 排法（8 种，开发一次永久复用）

每种排法自带"能装多少"的容量，程序拿这个容量去对账，不靠 AI 自觉：

| 排法 | 一页能装 | 什么时候用 |
| --- | --- | --- |
| 大图 + 一句话 | 1 张图 + 标题 + 60 字内 | 封面、最终作品、获奖 |
| 图文左右 | 1 张图 + 120 字内 | 最通用，正文偏长时 |
| 两张对照 | 2 张图 + 两个小标签 + 60 字 | 修改前后、草图对比 |
| 三图拼贴 | 3 张图 + 标题 | 多个方案、灵感素材 |
| 过程三步 | 3～5 组（图 + 20 字内） | 创作过程、步骤 |
| 纯文字便签 | 200 字内，可以没有图 | 只写了字、没画草图的孩子 |
| 大字引言 | 40 字内一句话 | 收获、金句、老师评语 |
| 封面海报式 | 1 张图铺满 + 标题 + 学生姓名 | 期末汇报、对外展示 |

尺寸由样式自己算（不是钉死坐标），所以**永远不会溢出**，不需要把句子一个字一个字切开。

### 3.3 配方（每章允许哪几种排法）

章节从 8 章收敛到 6 章，因为孩子记录本来就没那么多，凑不满的章节只会用套话填，那才是"模板味"的来源。

| 章节 | 允许的排法 | 缺内容时 |
| --- | --- | --- |
| 封面 | 大图 + 一句话、封面海报式 | 必备 |
| 我的想法 | 图文左右、纯文字便签、三图拼贴 | 有文字就能成页 |
| 我是怎么做的 | 过程三步、两张对照、三图拼贴 | 没过程就整章不要 |
| 我试了几种 | 三图拼贴、两张对照 | 版本少于 2 个，**这一章不出现** |
| 我选了这个 | 图文左右、大字引言 | 只写能核对的变化，不编理由 |
| 我的收获 | 大字引言、大图 + 一句话、纯文字便签 | 没写就跳过 |

**缺章跳过，不补空页。** 这一条决定报告看起来像孩子自己写的，还是像机器生成的。

### 3.4 内容模型（每段内容带"来源"标签）

内容不再是一大段文字，而是拆成小块，每块标明来源：

- `孩子自己写` —— AI 一个字都不许改事实
- `系统记录` —— 从项目里读出来的（几个版本、几张草图）
- `AI 整理` —— 润色、起标题，前台可标注"AI 协助"

块类型只有 6 种：小标题、正文、便签、两图对照、拼贴、过程条目。排法就是从这些块里挑着摆。

## 四、智能到底怎么来的（三级，从免费到花钱）

现在的误区是"智能排版 = 让大模型摆位置"。实际上大部分"聪明"来自**先把内容读成结构**。

| 级别 | 做什么 | 花钱 | 挂了怎么办 |
| --- | --- | --- | --- |
| 第一级 · 规则 | 看几张图、多少字，直接选排法 | 不花钱 | 本身不会挂 |
| 第二级 · 读结构 | 判断这两张图是"前后对照"还是"两个方案"；这段是问题还是感受 | 不花钱 | 判断不出就按第一级处理 |
| 第三级 · AI 编排 | 起标题、精简长句、决定哪几章保留、挑封面主图 | 一份报告最多 1 次 | 失败就退回第一二级，报告照样出 |

**关键差别：**
- 断网、没配模型、余额不足 → 报告照样能生成，只是不够巧，并明确标注"未使用 AI 整理"
- 同一份内容换风格 → **不重新调 AI**，不花钱，只换皮肤重渲染
- 现在的链路每份报告可能多次调用 AI，新体系**更省**

## 五、学生端会看到什么（走一遍真实流程）

1. 打开报告页，先看到一句判断：**"你现在的材料能出 5 页，缺『过程』这一章，要不要补一张草图？"**
2. 选气质 → 选颜色，两下点完
3. 立刻看到**真实缩略预览**（用他自己的作品和文字，不是样例图）
4. 点生成，3～8 秒出报告；或者直接"保存草稿"
5. 不满意 → 点"换个风格"，**不重新生成内容、不花钱**，秒换
6. 提交审核 → 通过后分享，家长手机打开是真文字，能选中、能放大

第 5 步是这套体系最值钱的地方：家长觉得不错可以换套风格再发朋友圈。现在的绝对坐标体系做不到这件事，因为换风格等于重排所有位置。

## 六、后台会看到什么

不再有画布和拖控件，只有三个表单：

1. **风格库**：新建 / 复制一套 / 改配色 / 传贴纸 / 预览 / 发布
2. **章节配方**：勾选启用哪几章，每章允许哪几种排法
3. **开放范围**：哪个版本能用哪些风格

| 动作 | 现在 | 新体系 |
| --- | --- | --- |
| 做一套新风格 | 摆 56 个坐标元素，2～3 小时 | 填表 + 传贴纸，15～20 分钟 |
| 复制一套改配色 | 基本等于重做 | 三分钟 |
| 加一个章节类型 | 改代码 | 勾选 |

## 七、老体系怎么退（不硬删）

| 阶段 | 做什么 | 对用户的影响 |
| --- | --- | --- |
| 第一阶段 | 旧编辑器**冻结**：只读，不再新增模板 | 高级版照常用，零影响 |
| 第二阶段 | 高级版迁到新体系并验收通过 | 高级版学生换新体验，旧报告照旧能看 |
| 第三阶段 | 旧编辑器下线 | 需你单独确认后才做 |

**任何阶段都不删历史报告。** 老报告继续按自己的快照渲染，一条都不动。

## 八、分四期做，每期你都能验收

| 期 | 做什么 | 你能看到什么 |
| --- | --- | --- |
| **P1 骨架** | 1 套皮肤 + 8 种排法 + 6 章配方，**先不接 AI** | 拿 3 个真实孩子（1 张画 / 200 字 / 多版本）跑出真报告，手机上能点开 |
| **P2 智能** | 三级智能 + 换风格不重算 + 失败兜底 | 断网也能出报告；换风格秒换不花钱；AI 挂掉有明确提示 |
| **P3 后台** | 风格库表单 + 再上 3 套风格 | 你自己在后台 20 分钟做出一套新风格 |
| **P4 开放迁移** | 开放进阶版 → 高级版迁移 → 老编辑器冻结 | 学生端能选风格了；高级版不受影响 |

**P1 是最关键的一期**：先把"不靠 AI 也能出一份不空洞的报告"做出来。这一关过了，后面都是配置工作。

## 九、验收标准（8 条，都能用眼睛看）

1. 只有 1 张画、一句话的孩子 → 出 3 页以上，且**不出现**"我保存了 N 个作品版本"这类套话
2. 写了 200 字 + 1 张竖图 → 自动拆页，不溢出、不弹"请先调整模板"
3. 有 5 个版本的 → 出现"我试了几种"这一章；只有 1 个版本的 → 这一章不出现
4. 拔网线 / 关掉模型 → 报告照常生成，明确标注"未使用 AI 整理"
5. 同一份内容点"换风格" → 3 秒内换完，内容不变，不重新调 AI
6. 手机 390 宽打开 → 正文不小于 14px，没有横向滚动，文字能选中能放大
7. 后台做一套新风格 → 20 分钟内完成，不动任何一页排版
8. 关掉新体系开关 → 回到现在的样子，高级版和其他版本完全不受影响

## 十、明确不做（防止跑偏）

| 不做 | 原因 |
| --- | --- |
| 自由拖拽编辑器 | 已验证成本过高，正是现在难用的根源 |
| 每页让 AI 生成图片 | 中文文字不可控、字错改不了、单份成本高 |
| 学生自己调排版 | 学生只该"选风格 + 确认内容"，不碰布局 |
| 迁移或重做任何历史报告 | 没必要，老报告按自己的快照继续显示 |
| 一上线就删旧编辑器 | 高级版还在用，必须先冻结后迁移 |

**后续可以做（本期不做）**：同一份报告出横版（A4 打印）和竖版（朋友圈）两套版式——新体系天然支持，现在的坐标体系做不到。

## 十一、风险，我先说在前面

| 风险 | 说明 | 我的处理 |
| --- | --- | --- |
| **皮肤好不好看** | 这是审美活，不是技术活。骨架我能保证不崩，但"好看"要设计把关 | P1 先出 3 张静态样张给你和教学主管过目，好看再往下做 |

| 6 章和 8 章并存 | 后台管理员可能混淆 | 风格卡片上标明"适用章节模型" |
| 进阶版从未开放过 | 没有真实数据验证假设 | P1 就用 3 个真实项目跑，不看完不进入 P2 |
