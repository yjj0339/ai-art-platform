# 账号权限与数据隔离规则

## 强制原则

- 平台支持多机构、多校区；任何业务查询默认限制在当前机构范围。
- 学生只能访问自己的数据；家长只能访问绑定学生；教师只能访问负责班级；管理员只能访问授权机构或校区。
- 后端必须从登录会话确定当前用户，不能信任前端传入的用户ID、机构ID或角色。
- 退出登录只清理会话和本地缓存，不删除用户作品、报告、画布和任务。
- 同一账号在不同浏览器和设备登录后，必须从服务端恢复已保存数据。

## 数据归属

作品、画布、视频任务、3D任务、报告、课程、文件、Token记录和审核记录必须包含机构范围及所有者或授权关系。

## 作品公开流程

作品默认私有。学生提交公开申请后，先进行系统内容安全审核，再进入后台人工批量审核。只有人工审核通过且满足机构发布授权后，作品才能公开。

状态流转：`私有 → 已提交 → 自动拒绝 / 待人工审核 → 已通过 → 已公开 / 已撤回`。

## 禁止事项

- 不得以 `localStorage` 作为用户业务数据唯一来源。
- 不得只在前端隐藏按钮来限制权限。
- 不得让用户通过修改URL、请求参数或资源ID访问他人数据。
- 不得将私有作品、课程文件、报告或AI密钥公开到无权限用户。

## 当前实现边界

已实现 PostgreSQL 账号、按机构代码登录、HttpOnly 服务端会话、管理员接口限制，以及按机构和所有者双重过滤的用户私有文档接口。家长绑定学生、教师负责班级、作品审核等关系表已建立，但现有页面尚未全部迁移并接入这些后端授权判断。

在 AI 绘画、无限画布、作品墙、视频、3D 和报告页面完成服务端迁移前，浏览器中的旧 `localStorage` 数据只能视为演示或兼容缓存，不能视为正式多用户数据，也不得部署为正式生产功能。
