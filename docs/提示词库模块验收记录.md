# 提示词库模块验收记录

## 任务信息

- 任务名称：后台提示词管理模块及初级版/入门版学生端提示词库
- 日期：2026-08-23
- 用户目标：管理员可配置分类和提示词；初级版、入门版学生通过图标选择提示词组合进行 AI 绘画。
- 本次明确不做：不改变高级版、进阶版原有绘画流程；不新增真实 AI 模型或提示词优化接口。

## 实际修改

- `server/schema.sql`：新增按机构隔离的 `prompt_categories`、`prompts` 表及索引。
- `server/prompt-library-store.js`：实现正式 PostgreSQL 与演示降级数据的读取、保存、归档和删除。
- `server/index.js`：接入学生读取和管理员分类/提示词接口，并修复学生接口鉴权顺序。
- `src/services/promptLibraryGateway.js`：新增前端 API 网关。
- `src/components/PromptLibraryAdmin.vue`、`src/views/AdminDashboard.vue`：新增后台一级导航和管理界面。
- `src/views/PaintStudio.vue`：初级版、入门版显示三列图标提示词库，支持组合后写入提示词输入框；读取失败使用默认配置并提示。
- 图标扩展：分类和提示词支持上传 PNG/JPG/WEBP 图片，或调用现有 AI 图片生成接口生成图标；图片文件保存到 `AI_DATA_DIR/prompt-library-icons`，数据库保存资源地址。
