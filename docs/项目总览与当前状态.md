# 项目总览与当前状态

## 项目目标

面向学生、教师、家长、学校和校区管理员，提供安全、可持续迭代的 AI 创意美术教学平台。所有功能以真实可用、数据隔离、可恢复和可部署为前提。

## 当前阶段

项目正从本地演示和单浏览器状态，迁移到可部署的多学校、多校区、服务端账号与数据隔离架构。

## 用户角色

| 角色 | 核心职责 | 数据范围 |
|---|---|---|
| 学生 | 创作、学习、查看自己的作品和报告 | 仅本人 |
| 家长 | 查看绑定学生的学习和作品 | 仅绑定学生 |
| 教师 | 管理负责班级和课程 | 仅负责班级与课程 |
| 校区管理员 | 管理获授权校区 | 仅授权校区 |
| 机构管理员 | 管理本机构 | 仅本机构 |

## 模块状态原则

功能状态以 `功能基线与回归清单.md` 为准。技术检测通过后标记为“待用户验收”，只有用户实际确认后才可标记为“已完成”。

## 当前优先级

1. 建立真实账号、会话、机构范围和服务端数据隔离。
2. 修复并核验 AI 无限画布。
3. 将学生创作、作品和H5报告迁移到用户隔离的服务端数据。
4. 迁移视频、3D、课程、教师、家长和管理员模块。
5. 完成多机构回归、服务器部署和用户验收。
