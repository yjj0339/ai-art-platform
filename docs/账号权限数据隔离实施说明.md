# 账号、权限与数据隔离实施说明

## 本期范围

本期只扩展现有“账号权限”模块，不新增数据安全中心、备份恢复、异常告警、数据导出、永久删除审批或审计日志页面。

服务端已提供机构、校区、班级、家长绑定、教师负责班级、管理员授权范围、权限组、会话、个人文档、受保护资产与 AI 任务的结构。账号创建、编辑、绑定、停用、重置密码、会话撤销和权限组变更均写入服务端审计日志。

## 上线前配置

在 `server/.env` 中配置以下正式环境变量：

```dotenv
AUTH_MODE=server
DATABASE_URL=postgres://用户名:密码@数据库主机:5432/数据库名
SESSION_COOKIE_SECURE=true
APP_ORIGIN=https://你的正式域名
AI_DATA_DIR=/服务器持久化目录/ai-art-data
VITE_AUTH_MODE=server
```

生产后端缺少上述安全配置会拒绝启动；生产前端未设置 `VITE_AUTH_MODE=server` 会拒绝构建。`AI_DATA_DIR` 必须是服务器上的持久化卷，发布新版本不得覆盖该目录。

## 部署顺序

1. 先创建独立的 PostgreSQL 测试库并填写 `server/.env`。
2. 备份正式数据库与 `AI_DATA_DIR`；本次迁移不会清理未知数据或 `server/data`。
3. 执行 `pnpm db:migrate`，迁移为幂等增量操作。
4. 如首次初始化，填写 `DEFAULT_*`、`BOOTSTRAP_ADMIN_*` 后执行 `pnpm db:bootstrap-admin`。默认创建机构范围管理员；设置 `BOOTSTRAP_ADMIN_SCOPE=campus` 才创建校区范围管理员。
5. 执行 `TEST_DATABASE_URL=... node scripts/test-isolation.mjs`。测试地址必须包含 `test`，脚本拒绝连接非专用测试库。
6. 使用 `VITE_AUTH_MODE=server pnpm build` 进行生产构建，再在真实浏览器完成账号关系、退出重登和关键创作流程回归。

## 已落实的安全边界

- 正式模式使用 HttpOnly 会话；前端不保存 Mock Token。
- 学生仅能写自己的个人文档；家长、教师、管理员只读访问授权学生文档。
- 跨用户资源 ID 在接口和 RLS 中都返回 404，不暴露资源是否存在。
- 管理员范围由 `admin_scopes` 决定，前端角色、机构、校区、班级参数不作为授权依据。
- 账号“删除”执行停用并撤销会话，保留业务数据。
- 作品项目、草稿、无限画布、视频草稿和项目内的报告、视频、3D 元数据可从服务端文档恢复；浏览器本地存储仅保留界面偏好或演示模式兼容数据。
- 文件资产使用随机受保护路径与资产 ID，正式接口不接受任意本机路径。视频与 3D 供应商任务 ID 不返回浏览器，平台任务 ID 与提交账号绑定。

## 当前延期与待验证项

- 数据安全中心、审计日志界面、存储健康界面、备份恢复按钮、异常告警、数据导出和永久删除审批均不在本期。
- 3D 和视频供应商结果文件尚未完成“下载后转存为内部资产 ID”的闭环；正式模式已禁止通过任意供应商 URL 下载，需在下一期接入安全转存后再开放文件下载与预览。
- 课程、模板、图库设置、公开画廊审核、Token 账本和课程进度尚未全部迁移到 PostgreSQL；不能描述为“全部业务数据已经隔离”。
- 真实 A/B/C、多浏览器、后端重启与浏览器回归必须等独立 PostgreSQL 测试库配置完成后执行并留存结果。
