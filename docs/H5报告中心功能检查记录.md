# H5 报告中心功能检查记录

## 检查范围

- 后台：`/admin` 内的 H5 报告中心。
- 学生端：`/student/h5-report`。
- 家长与媒体：`/h5-report/public/:token`。
- 服务端：H5 配置草稿、配置发布、报告提交、审核、公开读取、点赞与评语接口。

## 接口链路实测

1. 保存 H5 配置草稿成功。
2. 发布配置成功，学生运行时只返回正式发布配置。
3. 带图片或视频素材的报告提交后进入 `pending`。
4. 管理员审核通过后状态变为 `published`，生成 32 位随机分享令牌。
5. 公共接口可读取已发布报告。
6. 无媒体的安全测试报告可按自动策略直接发布。
7. 管理员下架后状态变为 `offline`，原分享地址立即失效并返回 404。
8. 后端重启后报告记录仍然存在。
