# 试用说明（2026-11-27 版本）

这一版的重点有四块：

- 管理后台从头重做；
- 课程库存到服务器上；
- API 配置理清；
- 内置技能增加到 18 个。

用户端（小画家用的页面）界面没有动，只修了逻辑。

## 试用前准备

1. 按 `docs/部署说明.md` 更新代码、重启后端。最后一节「管理后台重做、课程库存服务端、出图兜底（2026-11-27）」是这次的注意事项。
2. **先搬旧课程**：用平时管理课程的那台电脑、那个管理员账号，打开一次后台「课程库管理」。以前存在这个浏览器里的课程会自动搬上服务器，每个账号只搬一次；没改过的内置示例课不搬。
3. 准备三种账号，各一个：管理员、讲师、小画家。
4. 设置讲师权限：在后台「账号权限 → 权限组」里，把讲师放进一个权限组，给这个组打开课程权限：
   - 查看课程库
   - 使用课程
   - 上传课程
   - 发放课程
5. 设置班级：在「账号权限 → 分部与班级」里，确认小画家在某个班级里。

## 管理员

**看一遍新后台**
- 左侧菜单分组，可以收起，菜单上方的搜索框能按页面名找页面。
- 每个页面的图标都是线条图标，头像不再用单字。

**课程库管理**
1. 点「上传新课程」，填课程名，用「上传视频」「上传课件」加内容，点「保存到课程库」。
2. 点课程卡片上的「授权」（或切到「课程授权」再选这门课），下面三种方式可以一起用，选好后点「保存授权」：
   - 勾讲师权限组：组里的讲师能用这门课；
   - 打开「全机构的小画家」：所有小画家都能看到；
   - 勾具体班级：只有这些班的小画家能看到。
3. 课程卡片上会显示授权给了谁。删除课程前会先弹确认框。

**API 配置**
- 参考图方式按接口地址和模型名自动识别，一般不用管。确实要改时，在平台编辑页的「参考图」一栏打开「手动指定」再选。
- 「检测连接（免费）」只读一下模型列表，不出图、不花钱。
  - 下面有个「检测连接时顺便真实出一张图」的选项，会产生 1 次出图费用，只在确实需要时勾。
- 「出图备用模型」：选一个备用模型后，主模型出错会自动换它出图，小画家只扣一次积分。
- 平台状态：某个平台连续出错 3 次会自动暂停一会儿（1 分钟起，最长 10 分钟），这期间直接走备用模型。想马上恢复，点「立即恢复」。
- 平台编辑页的模型列表里，每个模型后面可以填「显示名」，用户端下拉框里显示这个名字。
- 模型按名字自动归类成图像 / 视频 / 文字；归错了可以手动改，保存后用户端刷新即可。
- 火山方舟平台编辑页里的「图片水印」（官方开关）默认开着。关掉后点「保存配置」，之后新生成的图不带官方水印；对外发布作品时仍要注明是 AI 生成。

**H5报告中心**

如果看到「原绑定已失效，正在用全局默认」：
1. 每个版本的「当前版本绑定智能体」选「不绑定，使用全局H5默认智能体」；
2. 点页面底部「发布本次配置」。

如果想给 H5 报告单独配一个第一人称人设：
1. 先到「智能体配置」新建一个智能体，类型选「H5第一人称报告」，填好人设和规则，保存；
2. 再回到「H5报告中心」，给每个版本选它，然后「发布本次配置」。

**AI 创作伙伴**
- 技能列表里现在有 18 个内置技能。
- 排序靠前的 8 个会显示在用户端首页的技能卡上；其余的，小画家在 AI 伙伴里说需求就会自动用上。

**账号安全 → 登录锁定**
- 同一个网络连续输错太多次会被暂停登录，这里能看到被锁的网络，并一键解除。
- 只能看到、解除自己机构的。

## 讲师

1. 登录讲师端，进「课程库」：
   - 能看到自己建的课，以及管理员授权给自己权限组的课；
   - 没有某项权限时，页面上会写明。
2. 点「新建空白课程」，填课程名，点「发布并授权」。
3. 在列表里找到这门课，点「发放」：
   - 面板里列出机构真实的班级和小画家；
   - 同名的小画家会带上班级名，方便区分；
   - 勾好后点「保存发放」。
4. 管理员授权给权限组的课，行里写着「权限组授权，复制后可发放」：
   - 先点「复制」，复制出一份自己的课；
   - 再对复制出来的课点「发放」。
   - 这样讲师改不到管理员的原课。

## 小画家

1. 登录后进「课程选择」，只能看到发给自己的、已发布的课程：
   - 全机构的课；
   - 发给自己班级的课；
   - 单独发给自己的课。
2. 课程库里一门课都没有时，才会显示内置的示例课。
3. 拿到的课程数据里不包含「发给了哪些班、哪些人」的名单。

## 已知限制

- **全程只用模拟 AI 测试**，没有调用付费接口。真实出图、出视频、出 3D，以及检测连接、备用模型切换，要在正式服务器上用真实接口试一次。
- **讲师「发放」名单**列的是全机构的班级和小画家，没有按讲师所带的班级过滤。
- **技能玩法和 H5 报告目前不扣积分**：后台价目里的「H5 报告 40 积分 / 份」还没有生效，等确定收费规则后再接上。
- **课程选择题的答案**随课程数据一起发到用户端（课程页在浏览器里判分），这是原来的设计。
- **平台「冷却」状态只记在内存**：重启后清零，多台服务器部署时各算各的。
