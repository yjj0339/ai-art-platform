## 共用渲染规则检查

| 规则 | 结果 |
| --- | --- |
| `layout` 改变页面结构，不只改变颜色 | 通过代码与构建检查 |
| `theme` 控制主色、辅助色、强调色和背景 | 通过代码与构建检查 |
| `contentDensity` 控制内容间距与图文比例 | 通过代码与构建检查 |
| `moduleOrder` 控制章节顺序 | 通过代码检查 |
| `hiddenModules` 隐藏指定章节 | 通过代码检查 |
| `displayOptions` 控制分享、点赞、评语、下载和官网入口 | 通过代码检查 |
| AI 返回章节再次经过排序与隐藏处理 | 通过代码检查 |
| 后台、学生预览、公开成品共用同一渲染组件 | 通过引用检查与生产构建 |
| 缺少素材时不伪造作品 | 已实现友好空状态 |

## 权限与回退

- 学生运行时只读取状态为 `published` 的模板。
- 模板选择优先级为：学生已确认选择、课程默认、主题推荐、管理员版本默认。
- 学生可选模板继续使用管理员允许列表与课程允许列表的交集。
- 交集为空时回退管理员默认模板，并关闭学生自主选择。
- 已生成报告保存完整模板快照；后续停用模板不改变已有报告外观。

## 本轮测试结论

- 四款模板资源已统一放入项目正式资源目录，后台、学生端和公开页使用同一来源。
- 同一份页面数据会经过同一渲染器，但依照四种 `layout` 呈现明显不同结构。
- 生产构建通过，未新增轮播或页面设计器依赖。
- 真实设备尺寸的自动截图复核因内置浏览器安全策略阻止接管而未完成，需要按功能检查记录中的尺寸人工补验。
