# 后台功能清单与接口对照（2026-11-26 盘点）

用途：

1. 后台界面要从功能出发重新做。本文件就是新界面的功能清单，每个功能都必须在新界面里有入口。
2. 后端复查的对照表：每个功能对应哪些接口，逐项验证。

盘点方法：

- 服务端路由由脚本从 `server/index.js` 和 `server/risk-routes.js` 提取，共 238 条。
- 前端调用由脚本扫描 `src/` 下所有 `apiClient.*('/…')` 以及拼出来的 `/api/…` 地址。
- 交叉核对结果：前端 301 处字面量接口调用全部能对上服务端路由（方法和路径都对），没有调用不存在的接口。
- 服务端有 38 条路由前端从来没调用过，分类见第三节。

约定：

- 接口前缀都是 `/api`。
- `/api/admin/*` 统一要求管理员身份（`server/index.js` 鉴权段）。机构级操作在各 store 里还会再校验管理范围。

## 一、端口与运行方式

| 项目 | 值 | 位置 |
|---|---|---|
| 后端默认端口 | 3000（`PORT` 环境变量可改） | `server/index.js` |
| 前端开发端口 | 5173，`/api` 代理到后端 | `vite.config.js` |
| 跨域白名单 | `APP_ORIGIN`（逗号分隔） | `server/.env` |
| 登录模式 | `VITE_AUTH_MODE=server` / `AUTH_MODE=server` | `.env.local` / `server/.env` |
| 隔离测试环境 | mock AI 3999、测试后端 3100（`AI_DATA_DIR` 指向测试数据）、前端 5180 | 测试包，不影响 3000/5173 |

## 二、18 个后台菜单：功能与接口

### 1. 数据大盘（`AdminOverview.vue`）

- **功能**：
  - 今日新增与活跃、AI 调用次数与失败率、积分流水、接口可用率；
  - 待处理事项：风险记录、异常、待审作品。
- **接口**：`GET /admin/ops/overview`、`GET /admin/risk/overview`。
- **数据**：服务端。

### 2. 账号权限（`AdminDashboard.vue` · accounts；`accountPermissionStore.js`、`creditGateway.js`）

- **账号**：
  - 列表、搜索，按类型 / 分部 / 状态筛选；
  - 创建、编辑、删除；
  - 启用 / 停用、重置密码、强制退出全部设备；
  - 管理员的管理范围（整个机构或指定分部）、讲师负责的班级、独立权限；
  - 积分查看与调整；封禁 / 解封。
  - 接口：
    - `GET/POST /admin/accounts`、`PATCH/DELETE /admin/accounts/:id`；
    - `PUT /admin/accounts/:id/admin-scopes`、`PUT /admin/accounts/:id/teacher-classes`；
    - `POST /admin/accounts/:id/reset-password`、`DELETE /admin/accounts/:id/sessions`；
    - `GET /admin/account-options`；
    - `GET /admin/credits/:id`、`POST /admin/credits/adjust`；
    - `POST /admin/risk/bans`、`POST /admin/risk/bans/:id/lift`。
- **分部与班级**：
  - 新建 / 改名 / 删除分部，新建班级。
  - 接口：`POST /admin/campuses`、`PATCH/DELETE /admin/campuses/:id`、`POST /admin/classes`。
  - 缺口：`PATCH /admin/classes/:id`（改班级名）服务端有，界面没入口。
- **注册邀请码**：生成邀请码。接口：`POST /admin/enrollment-codes`、`GET /admin/organization-setup`。
- **权限组**：增删改、成员。接口：`GET/POST /admin/permission-groups`、`PATCH/DELETE /admin/permission-groups/:id`。
- **积分兑换码**：
  - 生成、导出、核对收款、作废。
  - 接口：`GET/POST /admin/credit-codes`、`POST /admin/credit-codes/:id/confirm|void`、`GET /admin/credit-codes/export`。
- **数据**：服务端。

### 3. 账号安全（`AdminRiskCenter.vue`、`AdminBanDialog.vue`）

- **功能**：
  - 风险记录（处理）、封禁名单（解封）、登录锁定（解除）；
  - 敏感词库（增删改、导入、导出）、识别规则（增删改）；
  - 拦截设置、检测工具（试一段文字）。
- **接口**：`/admin/risk/overview|events|events/handle|bans|bans/:id/lift|login-locks|login-locks/clear|words|words/:id|words/export|rules|rules/:id|settings|test`。
- **缺口**：`POST /admin/risk/words/delete`（批量删词）服务端有，界面没有批量删除。
- **数据**：服务端。

### 4. 课程库管理（`AdminDashboard.vue` · courses；`courseStore.js`、`coursePptConversion.js`）

- **功能**：
  - 上传课程（视频、PDF、PPT 转换）、编辑、分类、授权，批量上下架 / 删除。
- **接口**：
  - 上传类：`POST /course-video/upload`、`POST /course-pdf/upload|render`、`POST /course-ppt/convert`。
- **数据**：⚠️ **课程本身只存在浏览器本地**（`localStorage['art-studio-courses']`）。换设备、换浏览器，管理员和小画家都看不到。
  - 服务端已有完整的课程接口：
    - `GET/POST /courses`、`GET/PATCH/DELETE /courses/:id`、`POST /courses/bulk-status|bulk-delete`；
    - `GET/PUT /courses/:id/assignments`；
    - `GET /course-categories`、`POST /admin/course-categories`、`PATCH/DELETE /admin/course-categories/:id`。
  - 前端从没接上。**排进后端补齐：改成存服务端。**

### 5. H5 报告中心（`AdminDashboard.vue` · h5ReportTemplates；`H5TemplateStudio.vue`）

- **功能**：
  - 用户端版本配置、视觉模板（草稿 / 发布）、文案智能体、审核发布队列。
- **接口**：
  - `GET/POST /admin/h5-report-config`、`POST /admin/h5-report-config/draft|template`；
  - `GET /admin/h5-reports`、`PATCH /admin/h5-reports/:id/audit`；
  - `POST /admin/h5-visual-template-assets`、`POST /admin/h5-report-layout/generate`、`GET /admin/h5-report-layout/samples`。
- **缺口**：`POST /admin/h5-reports/:id/comments/delete`（删分享页留言）服务端有，界面没有入口。

### 6. 报告工作流库（`H5WorkflowLibraryPanel.vue`；`aiSkillGateway.js`）

- **功能**：工作流列表、编辑、封面（AI 生成 / 用画布第一页）、测试、发布、批量删除。
- **接口**：`GET /admin/h5-report-workflows`、`GET/PATCH /admin/h5-report-workflows/:id`、`POST …/:id/cover/ai|cover/canvas|publish|test`、`POST /admin/h5-report-workflows/bulk-delete`。

### 7. API 配置（`AdminDashboard.vue` · api）

- **功能**：
  - 平台列表、新建 / 编辑 / 删除、默认平台；
  - 模型列表（类型、开关）、测试连接；
  - 官方水印开关（火山方舟）。
- **接口**：`GET/POST /admin/ai-providers`、`DELETE /admin/ai-providers/:id`、`POST /admin/ai-providers/default|models|model-status|test`、`GET /ai/health`。
- **客户反馈**：页面里对接无限画布时加的「读取上游节点图像 / 文字能力」等开关看不懂。**要理清：能力尽量自动判断。**

### 8. AI 用量与计费（`AdminDashboard.vue` · creditBilling；`creditGateway.js`）

- **功能**：每类能力每天免费次数、超出扣多少积分、按模型单独定价、积分提示文案、积分概览。
- **接口**：`GET/PUT /admin/credit-prices`、`PUT /admin/credit-messages`、`GET /admin/credits/overview`。
- **缺口**：`GET /admin/credit-messages`（读提示文案）界面没用。

### 9. AI 玩法中心（`AiSkillCenter.vue`、`AiSkillPackagePanel.vue`；`aiSkillGateway.js`、`aiSkillPackageGateway.js`）

- **玩法**：
  - 列表、新建、复制、编辑、启用、上下线、发布、版本与回滚、封面上传。
  - 接口：`/admin/ai-skills`、`/admin/ai-skills/:id`、`…/copy|enable|publish|status|versions|versions/:v/restore`、`POST /admin/ai-skills/cover-assets`。
- **技能包**：
  - 导入 SKILL.md / zip / 文件夹，分类、编辑、批量改名 / 上下线 / 删除，转成玩法。
  - 接口：`/admin/ai-skill-packages`、`…/:id`、`…/:id/convert`、`…/bulk`、`…/import`、`/admin/ai-skill-package-categories`。
- **玩法编辑页**：`AdminAiSkillWorkflowPage.vue`、`AdminAiSkillStudentPage.vue`（`GET /admin/h5-report-config`、`POST /admin/h5-report-config/draft`）。

### 10. AI 图像功能管理（`ImageStyleAdmin.vue`；`imageStyleGateway.js`）

- **功能**：风格模板增删改、批量、排序，分组增删改，封面上传 / AI 生成封面，面板设置。
- **接口**：`/admin/image-styles`、`…/:id`、`…/batch`、`…/reorder`、`/admin/image-style-groups`、`…/:id`、`POST /admin/image-style-covers`。
- **数据**：⚠️ **面板设置**（默认分组、每行几个、面板标题、没有模板时的显示方式）**只存在管理员浏览器本地**。用户端绘画页也从自己浏览器的本地存储读。所以「设置已保存，用户端刷新后生效」对别的设备不成立。**排进后端补齐。**

### 11. 提示词库管理（`PromptLibraryAdmin.vue`；`promptLibraryGateway.js`）

- **功能**：分类增删改（停用 / 永久删除）、提示词增删改、图标上传。
- **接口**：`/admin/prompt-library`、`/admin/prompt-library/categories(/:id)`、`/admin/prompt-library/prompts(/:id)`、`POST /admin/prompt-library/icon-assets`。

### 12. 智能体配置（`AdminDashboard.vue` · agents）

- **功能**：报告智能体人设、生成规则、预览、调用记录（查看 / 清空）、恢复默认。
- **接口**：`GET/POST /admin/report-agent-config`、`POST …/preview|reset`、`GET …/logs`、`POST …/logs/clear`、`POST /report/generate`。

### 13. AI 创作伙伴（`AgentPartnerAdmin.vue`；`agentGateway.js`）

- **功能**：
  - 模型、形象、说话方式、能力开关；
  - 技能（SKILL.md）导入 / 试用 / 发布 / 停用 / 删除；
  - 调用记录。
- **接口**：`/admin/agent/*`（配置、技能、导入、试用、记录）。
- **缺口**：`GET /admin/agent/skills/:id/export`（导出技能）界面没入口。

### 14. 分类管理（`GalleryCategoryPanel.vue`）

- **功能**：作品广场分类增删改、排序，给作品归类。
- **接口**：`/admin/gallery-categories(/:id)`、`PUT /admin/gallery-categories/order`、`GET /admin/gallery-submissions`、`PUT /admin/gallery-submissions/:id/category`。

### 15. 内容审核（`GalleryAuditPanel.vue`；`galleryStore.js`）

- **功能**：审核策略设置、投稿队列（通过 / 下架 / 重试）、授权管理、试审（付费，测试环境不点）。
- **接口**：`GET/PUT /admin/gallery-audit-settings`、`GET /admin/gallery-submissions`、`PATCH /admin/gallery-submissions/:id`、`POST …/:id/retry`、`PUT /admin/gallery-consents/:id`、`GET /admin/gallery-jobs/:id`、`GET /admin/gallery-meta`、`POST /admin/gallery-trials`。

### 16. 工作台管理（`WorkbenchAdmin.vue`；`workbenchGateway.js`）

- **功能**：卡片封面图、整屏背景（图片 / 视频）、品牌 LOGO 的替换和恢复默认。
- **接口**：`GET/POST /admin/workbench-config`、`POST /admin/workbench-config/reset`、`POST/DELETE /admin/workbench-assets`。

### 17. 异常管理（`AdminOpsCenter.vue`）

- **功能**：服务器出错和 AI 调用失败记录，标记已解决。
- **接口**：`GET /admin/ops/errors`、`POST /admin/ops/errors/resolve`。

### 18. 系统设置（`AdminDashboard.vue` · settings）

- **功能**：平台基础信息、运行环境检查（后端健康、AI 服务健康）。
- **接口**：`GET /health`、`GET /ai/health`。

## 三、服务端有、前端没调用的 38 条路由

| 类别 | 路由 | 判断 |
|---|---|---|
| 静态资源（前端用 `<img>` / `<video>` 地址直接读） | `/public/h5-reports/:id/pages/:id`、`/public/h5-reports/:id/media/:n`、`/prompt-library-icons/*`、`/image-style-covers/*`、`/workbench-assets/*`、`/ai-skill-covers/*`、`/agent-images/*`、`/agent-skill-covers/*`、`/h5-visual-template-assets/*`、`/course-ppt-assets/*`、`/course-video-assets/*`、`/gallery/submissions/:id/image` | 正常，复查时实际打开验证 |
| 课程库（见第二节第 4 项） | `/courses*`、`/course-categories`、`/admin/course-categories*` | **要接上**（数据落服务端） |
| 后台缺入口 | `PATCH /admin/classes/:id`、`POST /admin/h5-reports/:id/comments/delete`、`POST /admin/risk/words/delete`、`GET /admin/agent/skills/:id/export`、`GET /admin/credit-messages` | 新后台界面补上入口 |
| 课程对话智能体 | `GET /student/course-dialog`、`POST /student/course-dialog/turn|answer`、`POST /ai/course-document/parse` | 用户端没接入；用户端界面不动，只在复查里确认接口本身可用 |
| 积分内部接口 | `POST /credits/preview|charge|refund`、`GET /credits/abilities` | 复查用途：出图扣费走服务端内部函数，这几条是否还需要对外开放 |
| 讲师 / 家人查看 | `GET /students`、`GET /students/:id/documents(/:id)` | 复查权限边界（只能看自己负责的） |
| 其他 | `GET /me/safety` | 用户端没用到，保留 |
