色盘方案对比 · 手绘板取色器 v3

下面三个色盘都是能真点的：在色环／色条上按住拖能转色相，在色块里拖能调浓淡明暗，右下角可以直接粘十六进制色号。 你贴的那张截图这次没传上来，所以我按业内最主流的三种做法各做了一个，你对照截图指一个，或者说「A 的环 + B 的色域方块」这种组合也行。

方案 A · 色环 + 环心色域

推荐

iPad 上 Procreate、画世界、概念画板都是这个长相

最近用过

为什么推荐给学生用
  • 一眼就懂——圈是颜色，中间是浓淡，不用教
  • 占地方小，竖屏也放得下
  • 短板：中间色块只有 100px，挑极深的颜色不够准

方案 B · 色条 + 色域方块

美术老师更顺手

Photoshop 拾色器、Figma、Krita 的做法

最近用过

为什么调色最准
  • 色域给得最大——158px 高，深浅层次分得开
  • 色条横着放，拖的时候一根手指不会挡住
  • 短板：长得像办公软件，小孩子第一眼不知道咋玩

方案 C · 圆盘 + 三角

老派专业

老版 Photoshop、Corel Painter 的经典色轮

最近用过

好看，但不建议用
  • 最有"专业软件"的样子，老师看着有感觉
  • 三角里三个角是纯色/白/黑，中间区域手指很难戳准
  • 小学生基本不会用，会一直问老师
