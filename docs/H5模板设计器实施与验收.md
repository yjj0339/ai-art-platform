# H5 模板设计器实施与验收

日期：2026-10-16。依据已确认的1号方案执行，不包含提交、推送或上线。

## 使用入口与实际能力

管理员进入「H5报告中心 → 视觉风格」，点击「新建蓝白手账」或复制现有模板。左侧管理页面，中间选择、拖动和缩放元素，右侧集中放置添加、属性、图层和页面设置。平板建议使用「全屏编辑」。原版预设及参数仍在下方折叠区。

右侧可上传图片和背景，添加文字和装饰，设置内容绑定、字体、大小、颜色、透明度、图片裁切、图层显隐和锁定；支持页面复制、调整顺序，以及本次编辑会话的撤销重做。草稿自动保存到服务端，也可手动保存。遇到配置冲突保留本地稿，可「复制为新模板」另存。

发布只更新当前模板；其他模板草稿保持原状态。发布前检查布局和官网地址，再到「版本与模板」授权高级版学生使用。新模板不会自动替换正式默认模板，不会自动启用实验中的无限画布策略。

学生沿用原报告入口选择模板。系统读取本人已保存项目，复用原AI内容整理，再请求结构化排版；中文字由程序渲染，使用同一布局在学生预览和手机报告展示。报告保存到服务端后提交原审核流程，审核通过后可分享和生成带对应报告二维码的海报。

## 素材与内容边界

| 来源 | 本轮接入方式 |
| --- | --- |
| 想法、提示词、课程记录 | 复用项目字段及现有内容整理接口 |
| 最终作品 | 优先使用已选最终版本；没有选择时提示确认当前作品 |
| 原始草图、优化草图 | 按明确字段绑定 |
| 已保存的AI版本 | 依次展示，超出当前图片槽时续页 |
| 3D、场景 | 使用已有图片预览；没有素材时跳过 |
| 完整无限画布节点历史 | 未接入；界面明确提示，不声称已覆盖全部时间线 |
| 任意参考图自动分析、AI生成装饰 | 本轮未实施，首套模板使用原创程序化纸张、胶带和便签元素 |

内容整理失败时明确标记，使用已保存的原始记录，不伪造AI点评或教师评语。排版失败时保留原稿，学生明确选择后才使用基础版式。没有创作记录时拒绝生成。

## 保存、权限与兼容

- 布局是现有模板中的可选字段，历史模板和报告没有该字段时继续使用原渲染路径，无需迁移业务数据。
- 服务端维护修订号，冲突返回409；新模板归属当前机构，机构之间不能互相读取或覆盖。学生、教师、家长不能编辑模板。
- 学生生成时按服务器项目归属读取素材；保存报告时校验生成凭证，并使用服务器暂存的可信快照，不接受客户端伪造布局。
- 待保存结果暂存24小时，最多保留50份；已保存报告按本人归属取回，服务重启后可继续查看或提交草稿。未保存结果过期或超出保留数量后需要重新生成。
- 模板更新不会重排旧报告。公开资源通过已审核报告的分享凭证读取，报告下架后旧分享接口和资源接口返回404。已经下载或截图的内容无法撤回。
- AI排版每个账号最多一个在途任务、每分钟最多6次；默认60秒超时、每次只尝试一个模型，不自动切换供应商重复计费。同内容和模板的生成结果可复用。
- 沿用当前服务端文件存储方式；多实例并行部署前需为配置写入增加共享锁或数据库存储，本轮没有改造既有持久化架构。

新增 `H5TemplateStudio.vue/.css`、`H5LayoutPage.vue`、`h5Layout.js` 和 `server/h5-layout.js`。增量接入原后台、模板状态、学生生成页、独立预览、报告列表入口、共用渲染器及公开报告页。服务端增加草稿修订、当前模板发布、授权样例、排版和受保护分享资源接口。

## 验证结果

真实模型：Agnes `agnes-2.5-flash` 已返回通过结构、边界和文字容量校验的单页布局，耗时约7.8秒。首次沙箱网络连接失败；经授权的外部网络复核成功。未发送学生资料或图片，没有重复循环调用。证据：`.workbuddy/evidence/h5-template-studio/real-ai/`。

完整验收：`node scripts/verify-h5-template-studio.mjs` **105/105通过**。使用独立本机 PostgreSQL、真实后端、Vite 和 Chromium 浏览器；测试库在结束后清理，正式配置及报告文件哈希未变。证据：`.workbuddy/evidence/h5-template-studio/e8fcb1bbde/`，包含 `results.json`、服务日志和各尺寸截图。模型成功及故障响应来自本机测试模型，不能替代真实供应商的多页效果验收。

`pnpm build` 通过（22.16秒）；服务端及两份脚本的语法检查、任务文件差异空白检查通过。保留原有 Sass legacy API、第三方 PURE 注解、空 chunk 与混合导入警告。所测浏览器没有未捕获运行错误；预期失败接口用于验证401、403、404、409、413、429、502和503处理，不作为异常隐藏。

### 本轮发现问题及处理

| 问题与影响 | 原因、处理与当前状态 |
| --- | --- |
| 草稿修订不稳定、保存后重复自动保存 | 默认配置更新时间参与修订计算，回传同步又触发脏状态；分别排除根更新时间和抑制回传触发。已修复，刷新与保存回归通过。 |
| 生成后页面可能未等待关联项目写入结束 | 保存链路未等待异步队列；新增等待和可重试失败提示。已修复，实际项目保存、列表重开与控制台检查通过。 |
| 文档匹配可能忽略显式指定的编号 | 多个条件并列匹配，可能读到同项目另一草稿；显式编号优先且同时校验项目。已修复，错误编号404验证通过。 |
| 只有成品图被当成空项目、超长文案可能被截断 | 创作记录判断字段不全、输入规范化静默截取；改用已支持素材源，超限明确413。已修复，精简项目与超限测试通过。 |
| 排版失败可能重复请求供应商 | 原HTTP层默认重试3次；仅新排版调用显式使用单次请求，旧调用默认行为保留。已修复，503上游调用计数验证通过。 |
| 私有素材分享和旧快照兼容 | 新布局引入私有图片引用；增加只读取已审核报告引用的资源地址，保留旧渲染分支。已验证共享、下架与三类旧报告。 |
| 浏览器测试误读项目状态 | 测试动态导入了不同状态上下文；改用页面实际Pinia实例，并检查选中项目和服务端草稿。属于测试程序问题，已修复，未修改共享项目状态来掩盖。 |

上述功能问题均已修复并复测；本轮没有数据库结构变更或业务数据迁移。未发现需要进一步处理的本轮已确认错误。完整发布验收尚未达到原20项的全部门槛，不能标记为已上线稳定版本。

## 运行与回退

保持原 `pnpm dev`、`pnpm build` 和端口约定，不新增依赖。服务端持久化目录需一并保护 H5 配置、报告、模板图片和待保存结果；详见部署说明新增章节。
