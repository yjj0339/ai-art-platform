## 学习进度与记录

进度由四个环节计算，每项 25%，不再采用固定课程百分比或作品数量推算。

1. 课程学习：学生点击「我已完成课程学习」，或真实视频播放结束。该确认不是强制观看时长检测。
2. 随堂练习：全部问题作答并提交；不要求全部答对。无练习的课程无需答题。
3. 创意记录：保存非空创意，修改后需重新保存。
4. 作品提交：前三项完成，且关联项目有真实图片终稿时，点击「提交课程作品」。保留项目与版本引用，不复制作品，也不公开到画廊。若提交版本被删除，不再显示课程已完成。

正式账号复用现有 `/api/me/documents` 接口，以 `course-learning` 类型和课程 ID 为资源键保存到 PostgreSQL。沿用本人、机构和角色权限，不修改数据库结构或后端接口。页面明确显示读取/保存错误，提供重试入口。

演示模式明确标注记录仅在当前浏览器保存，并按账号区分缓存。旧版无账号标识的 `art-studio-course-learning-*` 草稿缓存保留，不自动归入正式账号，避免错误归属。已有项目和作品不改写。
