# 无限画布 @引用修复 · 手动验证清单

> 验证对象：`src/views/CanvasStudio.vue` 中「@按钮引用上游节点到提示词」功能
> 修复内容：为 **视频节点** 与 **图片节点** 的提示词输入框补上 `:ref` 注册（此前缺失导致点击 @ 无反应）
> 准备：先确认本地已启动前端（5173）与后端（3000）

---

## 背景：功能链路（修复后应成立）

```
选中下游节点（视频/图片）
  → 节点下方出现 ReferenceStrip（可引用素材条）
  → 每个上游节点显示为 [缩略图/图标] [@按钮]
  → 点击 @按钮 → insertReferenceAtCaret(id, sourceId)
  → 从 generationConfigNodePromptRefs 找到该节点提示词输入框 DOM   ← 修复点
  → 恢复记忆的光标位置
  → 在光标处插入 chip（@名称 + ×）
```

---

## ✅ 测试场景 A：@按钮插入到「光标所在位置」（核心验证）

**前置**：画布上有 1 个文字/图片节点 A 作为上游，1 个视频（或图片）节点 B 作为下游，两者已连线。

| 步骤 | 操作 | 预期结果 | 通过 |
|---|---|---|---|
| A1 | 选中视频节点 B | 节点下方出现「可引用素材」条，上游 A 带 `@` 按钮 | ☐ |
| A2 | 在 B 的提示词框内输入 `一只猫在` | 文字显示在框内 | ☐ |
| A3 | 鼠标点击文字 **中间**（「一只」和「猫在」之间），不要移开 | 光标停留在中间 | ☐ |
| A4 | 点击素材条上 A 的 **@按钮** | **① chip（@A 名称）插入在光标处** ② 提示词变为 `一只猫 @A 在` | ☐ |
| A5 | 在 chip 后继续打字 `玩耍` | 显示 `一只猫 @A 在玩耍`，chip 保持在中间 | ☐ |
| A6 | 等待 2 秒 | 顶部保存状态变为「已保存」，无报错 | ☐ |

> 🔑 **判定标准**：A4 中 chip 是否出现在**光标所在位置**（中间），而不是末尾。这是本次修复的核心验证点。
