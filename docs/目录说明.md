# 文档目录说明

本目录存放当前项目说明、功能基线、验收、技术决策、部署资料和设计方案。

## 使用规则

- 新增需求、计划、验收和执行记录统一放在 `docs`；旧任务包仅作为归档资料。
- 设计草稿、界面提案和设计验收说明统一放在 `docs/设计方案`。
- 可运行的网站资源继续放在 `public`，不要将页面实际使用的资源移动到文档目录。
- 每个功能任务的任务说明、执行记录和验收清单继续保留在 `subtasks/编号-功能名称`。
- 运行日志统一放在项目根目录的 `logs`，不作为交付文档或版本管理内容。
